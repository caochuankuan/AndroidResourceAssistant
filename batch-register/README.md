# 批量注册工具

用于批量创建账号、初始化存档，并实时查看三个兑换码的领取结果。

## 功能

- 根据用户名开头自动生成连续账号，例如输入 `account`、数量 `3`，生成 `account1`、`account2`、`account3`
- 最终生成的用户名必须是 `6–20` 位数字、英文字母或符号
- 所有账号使用同一个 `6–32` 位密码
- 用户名和密码不允许包含中文、空格等非 ASCII 字符
- 可设置同时处理 `1`、`2`、`3` 或 `5` 个账号
- 自动完成注册、登录和初始存档保存
- 自动兑换以下兑换码：
  - `再见小鸟`
  - `VIP8888`
  - `VIP2345`
- 实时显示每个账号的基础流程和三个兑换结果
- 支持停止任务、重试未完成账号和导出 CSV

## 为什么需要本地服务

目标接口 `http://116.62.238.93/api` 没有开放浏览器跨域访问。直接双击 `index.html` 时，浏览器会拦截注册请求。

本目录提供了一个不依赖第三方包的 Node.js 服务：

1. 在本地提供网页；
2. 接收页面发出的同源 `/api/*` 请求；
3. 将请求转发到目标接口。

## 环境要求

- Node.js 18 或更高版本
- Chrome、Edge 或其他现代浏览器
- 如需后台常驻运行，可选安装 PM2

该工具的普通启动不需要执行 `npm install`。

## 普通启动

在项目根目录执行：

```bash
node batch-register/server.js
```

看到以下内容表示启动成功：

```text
批量注册页面：http://127.0.0.1:8765/batch-register/
按 Ctrl+C 停止服务
```

浏览器打开：

```text
http://127.0.0.1:8765/batch-register/
```

停止服务时，在运行服务的终端按 `Ctrl+C`。

## 使用 PM2 启动

如果尚未安装 PM2：

```bash
npm install -g pm2
```

在项目根目录启动服务：

```bash
pm2 start batch-register/server.js --name batch-register
```

查看运行状态：

```bash
pm2 status
```

查看日志：

```bash
pm2 logs batch-register
```

重启服务：

```bash
pm2 restart batch-register
```

停止服务：

```bash
pm2 stop batch-register
```

删除 PM2 中的服务记录：

```bash
pm2 delete batch-register
```

### 配置开机自启

先保存当前 PM2 进程列表：

```bash
pm2 save
```

生成系统开机启动配置：

```bash
pm2 startup
```

`pm2 startup` 会输出一条需要额外执行的命令。复制并执行该命令后，再执行一次：

```bash
pm2 save
```

## 页面使用方法

1. 填写“用户名开头”，最终生成的账号必须是 `6–20` 位数字、英文字母或符号。
2. 填写注册数量，范围为 `1` 到 `500`。
3. 填写所有账号共用的密码，密码必须是 `6–32` 位数字、英文字母或符号。
4. 选择同时处理的账号数量。接口不稳定时建议选择 `1` 或 `2`。
5. 点击“开始批量注册”。
6. 在结果表格中实时查看注册、初始化及三个兑换码的状态。
7. 任务结束后，可点击“重试未完成”继续处理失败或中断的账号。
8. 点击“导出 CSV”保存本次执行结果。

运行过程中可以点击“停止任务”。已经成功的步骤会保留，点击“重试未完成”时会从未完成的步骤继续。

## 账号处理流程

每个账号按以下顺序执行：

1. 调用 `/api/register` 注册账号；
2. 调用 `/api/login` 获取登录令牌；
3. 调用 `/api/save` 写入初始存档；
4. 调用 `/api/redeem/claim` 兑换 `再见小鸟`；
5. 调用 `/api/redeem/claim` 兑换 `VIP8888`；
6. 调用 `/api/redeem/claim` 兑换 `VIP2345`。

某个兑换码失败时，工具仍会继续尝试后续兑换码。

## 常见问题

### 直接双击 HTML 后请求失败

不要直接双击打开 `index.html`。请先启动 `server.js`，再访问：

```text
http://127.0.0.1:8765/batch-register/
```

### 提示端口 8765 已被占用

检查占用端口的进程：

```bash
lsof -i :8765
```

如果之前已经通过 PM2 启动过服务，可检查并重启：

```bash
pm2 status
pm2 restart batch-register
```

### 页面能打开，但所有请求都失败

依次检查：

1. 运行 `server.js` 的终端或 PM2 日志中是否有报错；
2. 当前设备能否访问 `http://116.62.238.93`；
3. 目标接口是否正在运行；
4. 请求是否因频率过高被限制，可将“同时处理”调整为 `1` 后重试。

PM2 日志命令：

```bash
pm2 logs batch-register
```

### 注册成功，但兑换失败

可能原因包括兑换码已领取、兑换码失效、账号初始化失败或目标接口暂时异常。将鼠标停留在失败状态上可以查看接口返回的错误信息，之后可使用“重试未完成”。

## 安全说明

- 密码只用于当前页面执行任务，不会写入浏览器本地存储。
- 本地服务只监听 `127.0.0.1:8765`，局域网和公网设备默认无法访问。
- 不要将本地服务改为监听公网地址，除非同时增加身份验证和访问控制。
- CSV 结果包含账号信息，请妥善保管导出的文件。
